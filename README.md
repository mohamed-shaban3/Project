# Tic-Tac-Toe AI (Minimax Algorithm)

An unbeatable Tic-Tac-Toe game built with **Python** and **Pygame**. This project demonstrates the implementation of the **Minimax Algorithm**, ensuring the AI never loses.

## 🚀 Features
* **Unbeatable AI:** Plays perfectly using the Minimax algorithm.
* **Interactive UI:** Clean and responsive interface built with Pygame.
* **Score Tracking:** Keeps track of Player wins, AI wins, and Draws.
* **Restart Functionality:** Press 'R' to reset the game at any time.

## 🛠️ Technologies Used
* **Python 3**
* **Pygame:** For the game engine and UI.
* **Numpy:** For efficient board management.
